# 星轨 · 心事星空（桌面版）

> 把你的日常待办化作星空，一个 exe 就能运行。

## 使用方式

### 首次安装

1. 下载 `star-track-desktop.exe`
2. **双击运行**
3. 弹出文件夹选择窗口，选择一个你方便的位置存放数据（比如 `D:/星轨数据`）
4. 安装程序会自动执行：
   - 把 exe 复制到你选择的目录
   - 在桌面创建快捷方式
   - 自动打开浏览器 → 进入星空
5. **以后从桌面快捷方式启动即可**

### 启动方式

- **日常使用**：双击桌面快捷方式「星轨 · 心事星空」
- **直接启动**：进入数据目录，双击 `star-track-desktop.exe`

### 默认账号

用户名：`pilot`
密码：`startrack`

### 修改密码

在数据目录找到 `.env` 文件，修改：

```ini
AUTH_USER=你的用户名
AUTH_PASS=你的密码
```

保存后重启程序即可生效。

### 数据目录结构

```
你选的位置/
├── star-track-desktop.exe       # 主程序
├── .env                         # 用户名和密码
├── data/
│   └── todo.db                  # SQLite 数据库（全部待办数据）
└── logs/
    └── server.log               # 运行日志
```

备份整个目录即可迁移全部数据。

### 重新安装 / 迁移

把原始 exe 复制到另一台电脑，双击重新走安装流程即可。旧数据可以手动拷进新数据目录。

## 构建方法

需要安装 Go 1.21+。

```bash
# 1. 进入项目目录
cd star-track-desktop

# 2. 安装依赖
go mod tidy

# 3. 编译为单文件 exe
go build -ldflags="-s -w" -o star-track-desktop.exe

# 4. 运行（会进入安装流程）
star-track-desktop.exe
```

编译后的 exe 约 8MB，零外部依赖。

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Go + modernc.org/sqlite |
| 前端 | 原生 PHP/JavaScript/CSS |
| 认证 | JWT（nonce 挑战 + SHA256 哈希） |
| 打包 | `embed` 静态资源嵌入二进制 |

## 功能清单

- 四象限任务视图
- 六大星球分类（自我/学习/运动/赚钱/家庭/恋爱）
- 多级子任务 + 进度自动聚合
- 手动拖拽进度条
- 时间轴预约（按小时槽位安排）
- 暗色/亮色双主题
- 星史台历（历史完成记录）
- CSV 导出

## 与 PHP 版的区别

- 无需 PHP 环境、无需 Web 服务器、无需 MySQL
- 双击即用，自动安装 + 创建快捷方式
- 数据完全本地化
